# Third-party provenance and licensing

`WiiU-GP-RE` publishes **original reverse-engineering work only**: our own
scripts, our own C/C++ test harnesses, our findings, and our own diffs against
upstream projects.

**No third-party source tree is vendored in this repository.** The upstream
projects this work builds on are large, separately-licensed codebases. They are
deliberately *not* committed here; `01-radio-kernel/upstream-pc2drc-patches/`
and `11-patches/` contain only diffs.

## Licensing of files in this repository

Files fall into two groups and carry different licenses:

1. **Original work** — everything without an upstream patch header (scripts,
   harnesses, docs, captures we generated):
   see the repository `LICENSE`.

2. **Patch files** in `01-radio-kernel/upstream-pc2drc-patches/` and
   `11-patches/` — these are our own diffs, but they modify GPLv2 / GPLv3 /
   BSD-2 upstreams. Each patch is provided **under the license of the upstream
   it applies to**, so that applying it cannot create a license conflict:

   | Patch | Upstream target | License |
   |---|---|---|
   | `kernel_above_5_11_mac80211.patch` | Linux mac80211 | GPLv2 |
   | `kernel_below_5_12_mac80211.patch` | Linux mac80211 | GPLv2 |
   | `mac80211_rx.patch` | Linux mac80211 | GPLv2 |
   | `tsf-kali-7.1.5.patch` | Linux mac80211 | GPLv2 |
   | `0001-paced-sender-and-idr-policy.patch` | libdrc (BSD-2) + x264 (GPLv2) | BSD-2 / GPLv2 per file touched |
   | `pc2drc-local-work.patch` | libdrc (BSD-2), hostapd (GPLv2), x264 (GPLv2), drcvncclient (GPLv3) | see per-file table below |

   Because `pc2drc-local-work.patch` touches files under several licenses, the
   per-target license mapping is written into the header of that file. Do not
   relicense it as a single work.

## What was deliberately stripped before publication

These were present in the working tree and are **excluded from this repository**:

| Content | Reason |
|---|---|
| `pc2drc/`, `research/libdrc`, `research/wozt-libdrc`, `research/barista-ref`, `research/drc-hostap`, `build/hostap-2.12`, `kernel/linux-source-7.1/` | Full third-party source trees — would relicense or misattribute upstream code |
| `build/openssl-1.0.1u.tar.gz`, `kernel/linux-source-7.1_*.deb` | Third-party redistributable tarballs — GitHub is not the right distribution point; link upstream |
| `out/libs/*.so` (`libavutil`, `libswscale`), `out/hostapd` | Prebuilt binaries of third-party GPL/LGPL code |
| Binary hunk for `drc-hostap/netboot/netboot` (22 KB) inside the original `pc2drc-local-work.patch` | A compiled GPLv2 binary was embedded as a base85 `GIT binary patch`; binary redistribution of hostapd is not what this repo is for |
| `libdrc-vnc/drcvncclient/src/.deps/*.Po`, `drcvncclient/config.h` | Autogenerated build artefacts, not source of interest (the `.Po` diff additionally contained third-party build metadata) |
| `capture/` (1.3 GB pcaps), `out/evidence/*.bin` | Live console traffic from a personal device; also exceeds GitHub file limits |
| `core.1`, `core.9`, `core.15` | Core dumps — contain process memory including pairing material |
| `pairing.env`, `run/pairing.env`, `run/get_psk.conf` | Live WPA2 PSK + console BSSID + GamePad MAC |

## Reproducing the upstream side

To rebuild the radio stack, clone upstream at the pinned revisions listed in
`_meta/source-map.tsv`, then apply the patches in order. The patches are
provided so you never need to download someone's modified tree from this repo.
